# Проектная работа "WebLarek. Плохой сервер.", спринт 17

## Описание проекта

Backend-приложение интернет-магазина WebLarek.

Реализованы:

- регистрация и авторизация пользователей;
- JWT-аутентификация;
- роли пользователей (пользователь/администратор);
- работа с товарами;
- оформление заказов;
- загрузка изображений;
- защита API от распространённых уязвимостей.

## Что исправлено

### XSS

- пользовательские данные очищаются через `sanitize-html`;
- опасный HTML не выводится через `dangerouslySetInnerHTML`.

### CSRF

- добавлена защита через `csurf`;
- токен получается через:

```
GET /auth/csrf-token
```

- защищены POST/PATCH/DELETE запросы.

### NoSQL-инъекции

- добавлена валидация входных данных;
- ограничены доступные поля обновления;
- проверяются параметры запросов.

### Переполнение буфера

Добавлены ограничения:

- длина строк;
- размер тела запроса;
- размер загружаемых файлов;
- количество элементов в массивах.

### ReDoS

- регулярные выражения сделаны безопаснее;
- поисковые запросы ограничены и экранируются.

### DDoS

Добавлено:

- `express-rate-limit`;
- ограничения запросов в nginx;
- настройка безопасности заголовков.

### Path Traversal

- загрузка файлов ограничена безопасной директорией;
- проверяются имена файлов.

### Безопасность аккаунтов

- пароли хранятся через `bcrypt`;
- секреты вынесены в `.env`;
- настроены сроки жизни JWT-токенов.
